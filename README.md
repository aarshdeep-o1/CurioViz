# 🌌 CurioViz — Understand Data Distribution Visually

CurioViz is a futuristic data visualization project that helps users explore 📊 Normal Distribution, ↔️ Skewness, 📐 Kurtosis, 🧱 Histograms, and 🔔 Bell Curves through interactive scientific-style visualizations and animations.



## 🚀 Features

✨ Interactive statistical visualizations
🌌 Scientific cosmos-inspired UI
📊 Normal Distribution analysis
↔️ Skewness visualization
📐 Kurtosis exploration
🧱 Histogram generation
🔔 Animated Bell Curve rendering
💫 Smooth animations & particle effects
📱 Fully responsive modern design

## 🛠️ Tech Stack

* 🐍 Python
* 📦 NumPy
* 📊 Matplotlib
* 🎨 Seaborn
* 🌐 HTML, CSS & JavaScript

## 📸 Preview

A sleek dark-space themed interface with glowing data visualizations and animated statistical curves.
